# Capstone project artifacts

This directory holds the data, saved results, model checkpoint, figures, and capstone documentation for the drinking-water-access forecasting project.

Expected layout:

- `data/`: `water.csv`, `urban_population.csv`, `unemployment.csv`
- `results/`: `model_comparison.csv`, `water_predictions.csv`
- `models/`: `water_transformer.pt`
- `figures/`: the three project plots
- `screenshots/`: figures regenerated by `code/water_forecast.py`
- `docs/`: installation and validation notes

The currently supplied outputs should be treated as provisional until they are regenerated from a clean run. Confirm the target indicator, prediction range, and all metrics against the final code before submission.

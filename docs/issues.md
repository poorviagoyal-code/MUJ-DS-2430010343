# Suggested GitHub issues

Create issues in this repository for your personal-repository work and in the team capstone repository for shared work. Assign clear owners and close issues from pull requests.

1. **Dataset collection:** download WHO water access and World Bank urban population/unemployment data; record source URLs, access dates, and indicator definitions.
2. **Data cleaning and merge:** filter and reshape inputs; validate keys, duplicate country-year rows, and missingness.
3. **Exploratory analysis:** generate and save distribution, time trend, and correlation summaries.
4. **Model development:** implement five-year windows and the chronological split; compare Linear Regression, Random Forest, Transformer, and naive repeat-last-year.
5. **Testing and evaluation:** compute MAE, RMSE, and R² on identical held-out rows; inspect prediction bounds and leakage risks.
6. **Documentation:** document setup, methods, findings, limitations, and reproducibility.
7. **Presentation:** reconcile all displayed metrics and charts with validated output artifacts.
8. **Final validation:** clean-run notebook/script and verify generated artifacts/checkpoint.
